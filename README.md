# 📊 Excel Data Analysis Project | Data Technician Bootcamp

## 🚀 Overview
This project was completed as part of a **Data Technician Bootcamp** and demonstrates practical Excel skills used to analyse retail and sales datasets. The work involved cleaning, exploring, summarising, and visualising data to identify trends and generate business insights.

## 🛠️ Skills Demonstrated

### 🔢 Excel Functions & Formulas
Applied a range of Excel formulas to automate calculations and data analysis:

- ➕ `SUM()` - Calculate total sales and revenue
- 🎯 `SUMIF()` - Perform conditional calculations
- 📈 `AVERAGE()` - Find average values across datasets
- 📊 `AVERAGEIF()` - Calculate conditional averages
- 📅 `DATE()`, `MONTH()`, `YEAR()` - Analyse and manipulate date-based data
- 🆔 `UNIQUE()` - Extract distinct values from datasets
- 🔍 `VLOOKUP()` - Retrieve information from related tables
- 🔄 `SWITCH()` - Categorise and classify sales performance

### 🧹 Data Management & Analysis
- ✅ Filtered datasets to focus on specific records and trends
- ✅ Sorted data in ascending and descending order
- ✅ Analysed retail and sales data to identify patterns
- ✅ Explored customer and product performance metrics

### 📋 PivotTables
Created PivotTables to:

- 📌 Summarise sales by product and location
- 🌍 Compare sales across countries and regions
- 👥 Analyse customer demographics
- 📈 Generate meaningful business insights from large datasets

### 📊 Data Visualisation
Designed charts and visual reports to:

- 📉 Track sales trends over time
- 🏆 Compare product performance
- 👥 Visualise customer segmentation
- 📢 Present insights in a clear and engaging format

## 🎯 Key Outcomes
- 💡 Developed strong Excel data analysis skills
- 📈 Improved ability to transform raw data into actionable insights
- 🔍 Enhanced understanding of data exploration and reporting
- 📊 Built interactive summaries using PivotTables and charts
- 🚀 Strengthened decision-making through data-driven analysis
